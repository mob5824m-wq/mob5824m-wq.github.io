# Screenshots

Drop project screenshots here, then reference one from `data/content.js`:

```js
shot: "assets/img/shots/classroom-library.png",
```

The card crops it to 16:9 anchored at the top, so the header of a tall
page screenshot stays visible. The popup shows more of it.

Tips:
- PNG for UI screenshots, JPEG for photos
- Keep each file under ~300 KB — resize to about 1200px wide first
- A card with a `shot` hides its icon automatically
