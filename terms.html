02 Description of Service

Punishment Manager is a dedicated moderation and role-management application created for Discord servers. The Bot facilitates:

  • Automated Role Swaps: Temporarily applying a designated punishment role when an authorized moderator issues a command.
  • Expiration Timers: Automatically transitioning the user to a post-punishment or restored role state when the specified duration concludes.
  • Notification Embeds: Sending structured rich embeds to configured staff moderation logging channels and direct messages (DMs) to punished users explaining the reason and duration.
  • Audit Persistence: Storing active punishments and punishment history in an SQLite database to maintain timers across bot restarts.
Punishment Manager provides automation tools for Discord community staff. The Bot executes moderation decisions initiated by humans and does not independently monitor or censor user conversations outside of explicit slash commands.

06 Commands & Discord Permissions

The Bot relies on specific Discord permissions to function effectively:

Command Required Role / Permission Functionality
/setup Server Administrators Configures punishment roles, post-punish roles, staff log channels, and DM preferences.
/punish apply Moderate Members / Staff Applies designated punishment role, schedules expiration timer, sends log embed & user DM.
/punish pardon Moderate Members / Staff Early termination of punishment; clears punishment role and updates audit records.
/punish status Guild Members Displays active guild punishment configuration and per-user moderation history.
