A clear operations desk

Less busywork between staff and the server.

A self-hosted Python bot with a focused set of tools for keeping a community informed, involved, and supported.

Announcements on your schedule

Post now, schedule a message, or repeat it on an interval. Reuse templates, request a second staff approval, set quiet hours, and pin posts for a while.

Polls and events

Create single- or multiple-choice button polls, schedule them, and close them automatically. Post events with RSVP reactions and configurable reminders.

Private support tickets

Open a private channel from a ticket panel, close it when resolved, and optionally auto-close idle tickets. A transcript is saved for staff before the channel is deleted.

Roles and welcomes

Give or remove roles with reactions and dropdown role menus. Set a welcome message for new members, with server-specific staff controls.

Accountable staff actions

Review a newest-first audit trail of staff actions from Discord, the dashboard, and the scheduler. Approval requests keep a second set of eyes on selected announcements.

Browser dashboard

Use the same operations in a browser dashboard running in the bot process. It listens on loopback by default; remote exposure is an operator-managed security decision.

Installation & Setup

Host Combat Master for your staff.

Self-hosted Python bot with SQLite, data isolation, and a browser operations dashboard.

Installation Steps

  1. 1. Clone the repository

    git clone https://github.com/mob5824m-wq/Combat-Master.git && cd Combat-Master

  2. 2. Install requirements

    python3 -m pip install -r requirements.txt
    Requires Python 3.9 or higher.

  3. 3. Configure Token

    export DISCORD_TOKEN="your-bot-token"
    Or place credentials in data/config.json.

  4. 4. Run the Bot

    python3 bot.py
    Launch helpers: scripts/run_linux.sh or scripts\run_windows.bat.

How to Use

  1. 1. Configure server channels & staff role

    /manage setup staff_role:@Staff announcement_channel:#announcements staff_channel:#staff-log

  2. 2. Announcements & Schedules

    /manage announce
    Schedule future posts with /manage schedule delay:2h or repeating posts with /manage repeat.

  3. 3. Interactive Polls & Tickets

    Create vote button polls with /manage poll create and deploy support channels with /manage ticket panel.

  4. 4. Web Operations Dashboard

    Open http://localhost:8000 to manage polls, tickets, schedules, and view audit history.

From install to /manage

Your server, your controls.

Combat Master runs on infrastructure you choose. Discord privileged intents are required for welcome messages and ticket transcript handling.

01 / INSTALL

Choose a host

Follow the repository setup guide and use the included launch script for Windows or Linux. Your instance writes its database, live config, and log to its data directory.

02 / CONFIGURE

Set staff access

Connect a Discord application, configure its staff role and channels, and grant only the permissions required by the features you enable.

03 / OPERATE

Work from /manage

Use Discord slash commands or the authenticated dashboard. The server operator controls the bot token, dashboard access, stored records, and backups.

Built for staff operations—not moderation punishments.

Combat Master focuses on announcements, polls, events, tickets, and roles. It does not include moderation punishments or warnings, applications, music, voice, or streaming tools.
