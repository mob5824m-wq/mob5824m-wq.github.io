Automated Home Cloud

Repurpose old hardware into a modern NAS.

Never pay for Google One cloud storage again. Keep your original files safely while uploading optimized versions through your Pixel's grandfathered unlimited backup perk.

Closet NAS Server APK

Runs natively on Google Pixel 1 through Pixel 5. Serves Samba SMB2/SMB3 file shares, WebDAV, FTP (:2121), and a browser Web UI on port 8080.

Automated Storage Saver

Automatically downsamples >16.0 MP photos to ≤16.0 MP and 4K videos to 1080p, preserving complete EXIF dates and coordinates before notifying Android MediaStore.

Household Client App

Lightweight APK for every family member's Android phone with 1-tap Wi-Fi discovery, automatic camera-roll sync, system share sheet, and desktop upload widget.

Google Photos Unlimited

Trigger Google Photos' free grandfathered tier directly from the Pixel's local folder. Eliminates subscription fees while keeping photos accessible worldwide.

Installation & Setup

Setup Pixel Photo NAS in 3 steps.

Deploy the Server APK on your closet Pixel, and install the Household Client APK on family phones.

Installation Steps

  1. 1. Install Server APK on your closet Pixel

    Download and install PixelPhotoNAS-v1.0.0-Pixel1to5-Signed.apk on a Pixel 1, 2, 3, 4, or 5.

  2. 2. Install Household Client APK on family phones

    Install PixelPhotoNAS-Household-v1.0.0-SambaClient-Signed.apk on each family member's daily Android device.

  3. 3. Standalone Python Server (Optional for Linux / Termux)

    git clone https://github.com/mob5824m-wq/Photo-Convert-Aindroid.git && cd Photo-Convert-Aindroid && pip install -r requirements.txt && python3 -m server.main

How to Use

  1. 1. Start NAS daemon on the Pixel

    Grant "All Files Access" and turn on the daemon. It exposes \\<pixel-ip>\PixelNAS on port 4445 plus the web manager on :8080.

  2. 2. Configure Google Photos on the Pixel

    In Google Photos → Collections → On this device, enable Backup for the PixelNAS folder.

  3. 3. Connect from Household Client App

    Open the app, tap Scan Wi-Fi for Samba NAS, choose your member name (Mom, Dad, Alex), and pin the upload widget to your home screen!

Device Compatibility

Recommended hardware.

Unlimited Original Quality. Best for pure raw backup without any downsampling.

SAVER

Unlimited Storage Saver (≤16MP, 1080p). Highly responsive and power efficient.

IDEAL

Pixel 5 / Pixel 4a 5G

Snapdragon 765G with 6–8 GB RAM and 128 GB UFS. Ideal 24/7 cool-running closet NAS hardware.
