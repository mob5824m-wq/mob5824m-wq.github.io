Search civic records in Kitchener & Waterloo.

A fast, dependency-free web tool that queries municipal open-data services directly from the browser. Look up corporate and institutional property portfolios, or search any civic address to view historical building permits and interactive vector maps.

Transparent Civic Data

Accessible public records for everyone.

No paywalls, subscriptions, or login forms. Explore municipal property footprints with honest data explanations.

Owner Portfolios

Search a business, university, or numbered corporation to see every commercial building and parcel linked to it, grouped cleanly by civic address.

Building Permits

Search any street address in Kitchener or Waterloo to view construction permit dates, declared project values, contractor scopes, and current status.

Offline-Capable Map

Displays street layers from keyless ArcGIS Online or falls back to an SVG coordinate drafting canvas so parcels are always positioned reliably.

CSV & Print Export

Download full structured CSV datasets for research or press Print for clean ink-saving black-and-white property dossiers.

Installation & Setup

Run Ledger KW.

No build step or npm packages required. Launch instantly using Python or any static web server.

Installation Steps

  1. 1. Clone the repository

    git clone https://github.com/mob5824m-wq/City-Search.git && cd City-Search

  2. 2. Start preview server

    python3 server.py
    Or run python3 -m http.server 8000 or npm start.

How to Use

  1. 1. Open application

    http://localhost:8000

  2. 2. Search corporate owner portfolios

    Type a corporate or institutional name (e.g. "University of Waterloo" or "Drewlo") to see all attributed properties and units.

  3. 3. Search civic address records

    Enter any street number and name in Kitchener or Waterloo to view building permit records, construction costs, and ward information.

  4. 4. Export data

    Click Export CSV to save tabular data, or use browser print for clean printout records.

Data Governance

Ontario Open Data transparency.

Public open data has distinct legal boundaries under Ontario law.

MFIPPA

Privacy Protection

Individual residential homeowners are marked PRIVATE under provincial privacy legislation and excluded from open data.

ONLAND

Title Searches

This is not a legal title search. For official legal ownership, users are directed to official ONLAND and MPAC registries.

OPEN

Direct GIS Endpoints

All data is retrieved live from the cities' ArcGIS open data servers with zero intermediate tracking or scraping databases.
