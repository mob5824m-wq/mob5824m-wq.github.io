Made for the day-to-day

A focused toolkit for server staff.

Keep routine moderation and application decisions in one self-hosted bot, with records stored on the machine you control.

Measured moderation

Timed role punishments, pardons, and warnings use staff checks and role safeguards. View a member’s recorded history when context matters.

Staff-reviewed applications

Create forms, publish an application panel, and review submissions with authorized staff. Decisions and optional roles follow the server’s setup.

Authenticated dashboard

Manage connected servers, moderation, applications, settings, and history in a web dashboard that listens on the local machine by default.

Persistent local records

SQLite keeps active punishment timers available after a restart and holds warning, history, and application records on your host.
