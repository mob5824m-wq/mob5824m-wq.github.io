02 The Software

Sentinel is a Discord bot with staff tools grouped under /manage. Depending on version and server configuration, it can apply timed role changes, record warnings and moderation history, and collect and route applications for staff review. A dashboard offers authenticated controls for supported server, moderation, application, configuration, and history features.

Sentinel automates actions configured or requested by server staff; it does not decide whether a member has broken a rule, assess the fairness of a decision, or guarantee that Discord will carry out an action. The server and its staff remain responsible for their community policies and moderation outcomes.

04 Server Operator Responsibilities

Server owners and administrators are responsible for choosing whether Sentinel is appropriate for their community and for configuring it safely. They agree to:

  • Grant only the Discord permissions needed for enabled features, and keep Sentinel’s role and configured roles in an appropriate order.
  • Choose trustworthy staff and review moderation actions, application access, role assignments, and server settings.
  • Tell members what information an application requests and who can review it; avoid collecting passwords, payment details, or unnecessary sensitive information.
  • Secure the host, bot token, dashboard key, configuration, database, logs, and backups; limit access to the dashboard and stored records.
  • Set and carry out suitable retention and deletion practices for their instance and for messages sent to Discord.

Removing Sentinel from a Discord server does not necessarily stop a separately running process or erase files from its host. The instance operator must stop the program and handle local data.

05 Applications & User Content

Application answers, form text, moderation reasons, decision notes, and other text submitted through Sentinel are provided by members or server staff. Submit only information you have permission to share. Server operators and the staff they authorize may be able to read application answers and moderation records in Discord or through the dashboard.

Server operators—not the Maintainer—decide what questions to ask, who can review submissions, and how long they keep records. Do not use the bot to expose private information, harass someone, or make a submission under another person’s identity.

06 Permissions & Security

Sentinel can only act within the permissions Discord and a server grant it. Its dashboard is configured to listen on the local machine by default and requires a dashboard credential. If an operator makes the dashboard remotely reachable, the operator is responsible for using HTTPS, a suitable firewall or trusted proxy, a strong private credential, and appropriate access restrictions.

No software or configuration can guarantee absolute security. Do not publish bot tokens, dashboard keys, or other credentials in a repository, screenshot, issue, or chat. If a credential is exposed, the operator should revoke or replace it promptly.
