Working Over-The-Air Portal

Root and install the complete suite directly from the stock tablet browser with zero redirects, or spin up a local multi-threaded Wi-Fi server on your PC.

Clean Stock Android Home

Replaces sluggish Kobo Tapestry with clean Vanilla Android 4 Home (v49). Supports long-press widgets and removes discontinued preloads and bloatware.

Atomic Clock & Timezone Sync

Queries Wi-Fi geolocation to configure accurate IANA timezones (e.g. America/Toronto) and synchronizes kernel UTC time to prevent SSL certificate handshake errors.

Installs static ARMv7 python3, pip, curl, and apt into /system/xbin/, enabling full local script development in Arc7 Terminal.

Installation & Setup

Install Kobo Arc 7 Freedom.

Choose between over-the-air web installation on the tablet or local Wi-Fi streaming from a computer.

Installation Steps

  1. Option A: Direct OTA Web Portal (Easiest)

    https://mob5824m-wq.github.io/Kobo-Arc-7-freedom/
    Open this link directly in the tablet's stock web browser.

  2. Option B: Local Wi-Fi Rooting Server (For Fresh Tablets)

    Windows: Start-Kobo-WiFi-Server.bat
    macOS/Linux: ./Start-Kobo-WiFi-Server.sh
    Runs a local zero-SSL concurrent HTTP server on your computer.

  3. Download & Install 1-Tap Upgrader APK

    Tap Upgrade-My-Kobo-To-v1.9.1.apk from the portal to install the full suite automatically.

How to Use

  1. 1. Execute 1-Tap Root

    Open Kobo Arc 7 Freedom app on the tablet, tap 1-Tap Root, and wait while it installs su, cleans bloatware, and syncs system clocks.

  2. 2. Install apps with Aurora Store & F-Droid

    Launch Aurora Store (bundled with auto SHA1-RSA jar signers) or F-Droid Classic with the included TLS 1.3 bridge to download Android 4.2 apps.

  3. 3. Use Linux terminal utilities

    Open terminal and run python3, curl, or apt install <package> natively.
