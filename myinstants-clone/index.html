Installation & Setup

Run MyInstants Clone.

Static web application requiring zero dependencies, compilers, or build steps.

Installation Steps

  1. 1. Clone the repository

    git clone https://github.com/mob5824m-wq/Myinstantsclone.git && cd Myinstantsclone

  2. 2. Start static HTTP server

    python3 -m http.server 8000
    Or use any static hosting environment (GitHub Pages, Netlify, Nginx).

How to Use

  1. 1. Open soundboard

    http://localhost:8000

  2. 2. Play instant sounds

    Click or tap any 3D button to play. Adjust master volume or toggle the "Overlap" switch for simultaneous sounds.

  3. 3. Search & favorites

    Type in the search box to find sound memes, or click the heart button to save clips to your Favorites list.

  4. 4. Upload your own clips

    Use the upload panel to drag and drop audio files, generating custom instant buttons instantly.

Architecture

Graceful audio degradation.

Never encounter a silent or broken button.

01 / CDN

Direct MP3 streaming

Sound clips stream directly from cloud CDN with zero server bandwidth required on your host.

02 / SYNTH

Web Audio engine

If network connection fails or a sound is offline, the client synthesizer generates procedural audio.

03 / BADGES

Visual playback status

Badges clearly indicate whether each sound played from authentic MP3 media or the synth engine.
