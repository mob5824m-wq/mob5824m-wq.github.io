Soundtrail Support provides an end-to-end help desk right inside your Discord server.

Interactive Ticket Panel

Buttons for Technical issue, Account help, and General questions create private ticket channels visible only to the member and authorized staff.

Saved Transcripts

Before a ticket channel is removed, all messages, timestamps, authors, and attachment links are compiled into an HTML/text transcript for staff review.

Canned FAQ Replies

Save common troubleshooting guides using /manage faq save and insert them directly into open tickets with /manage faq use without pinging members.

Support Hours & Quiet Time

Define operating hours to automatically inform members if they submit inquiries after hours, and prevent late-night announcement bursts.

Installation & Setup

Run Soundtrail Support Bot.

Self-hosted Python 3.9+ bot with SQLite persistence and browser management dashboard.

Installation Steps

  1. 1. Clone the repository

    git clone https://github.com/mob5824m-wq/Soundtrail-Bot.git && cd Soundtrail-Bot

  2. 2. Install Python dependencies

    python3 -m pip install -r requirements.txt
    Requires Python 3.9 or higher.

  3. 3. Configure Bot Token

    export DISCORD_TOKEN="your-bot-token"
    Or save inside data/config.json.

  4. 4. Launch the Bot

    python3 bot.py
    Helpers: scripts/run_linux.sh or scripts\run_windows.bat.

How to Use

  1. 1. Discord Bot Gateway Intents

    In Discord Developer Portal, enable Server Members Intent and Message Content Intent.

  2. 2. Server configuration

    /manage setup staff_role:@Support ticket_category:Support timezone:America/Toronto

  3. 3. Deploy Support Ticket Panel

    /manage ticket panel
    Posts the interactive ticket creation embed in your channel.

  4. 4. Staff Dashboard

    Visit http://localhost:8000 to view live ticket queues, download transcripts, and inspect audit logs.

Security & Data Control

Self-hosted data governance.

You own your community records. All data is kept on the host you choose.

01 / LOCAL

Isolated SQLite database

Tickets, settings, FAQs, and audit logs are stored in a local SQLite file in your data directory.

02 / ROLES

Staff privilege gate

Commands verify the caller's server role and permissions on every invocation.

03 / RETENTION

Configurable retention

Set transcript retention periods from 1 to 3,650 days with automatic expiration of local files.
