Privacy Policy

Self-hosted Discord BotEffective: October 20, 2026

Overview Data processed Tickets & transcripts Storage & access Data retention

Overview

Soundtrail Support Bot is self-hosted. By default, all data processed by the bot stays on the host machine running the software. Neither the author nor any central server receives your community's messages or tickets.

Data processed

The bot processes Discord user IDs, channel IDs, guild IDs, role assignments, and message content within active ticket channels for support workflows.

Tickets & transcripts

When an authorized staff member closes a support ticket, the bot reads the message history of the channel and generates an archival transcript containing message text, timestamps, and usernames.

Storage & access

All records are stored in a local SQLite database in the instance's configured data directory. Access to the dashboard is protected by cryptographic tokens generated on startup.

Data retention

Instance administrators can configure automatic transcript expiration via /manage setup transcript_retention_days. Expired local transcripts are purged automatically.
